# Features Architecture

This directory follows Feature-Based Architecture as defined in `ARCHITECTURE.md`.

Business feature modules will be added here in upcoming milestones:

- `features/chat/`
- `features/weather/`
- `features/disease-detection/`
- `features/market/`
- `features/voice/`

Each feature module will encapsulate its own components, hooks, services, types, and state.
No business feature logic exists in Phase 1 (Foundation).
