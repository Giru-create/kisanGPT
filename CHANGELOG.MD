# Versioning

Use Semantic Versioning.

MAJOR.MINOR.PATCH

Examples:

- 0.1.0
- 0.2.0
- 0.2.1
- 1.0.0

Increment:

PATCH → Bug fixes

MINOR → New features

MAJOR → Breaking changes
